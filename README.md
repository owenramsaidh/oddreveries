# Odd Reveries

The site for Odd Reveries, by Owen Ramsaidh.

- Photos go in `src/images/bw-tales/` and `src/images/faylene/`, named in order (`bw-tales-01.jpg`, `faylene-01.jpg` …). Web copies only: 2560 px long edge, sRGB, metadata stripped.
- Gallery text, titles and captions live in `src/galleries/`. The editor at `/admin/` changes them for you.
- Cloudflare Pages builds it: build command `npm run build`, output folder `_site`.
